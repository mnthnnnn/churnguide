Methodology & Implementation

Standardized distance metrics and unsupervised partitioning.

Customer segments are generated using K-Means clustering ($k={{ seg_data.k }}$) applied dynamically to all confirmed numeric features ({{ seg_data.numeric_features|join(', ') }}).

Missing numeric values are imputed with median estimators prior to $z$-score feature standardization: $$z = \frac{x - \mu}{\sigma}$$

Theoretical Note: Clustering is computed purely on features without exposure to the churn target, preventing target leakage during cohort discovery. Empirical churn rates are calculated retroactively across discovered clusters.
